# Log Filter (Fabric, Minecraft 26.3)

Hides log lines from mods you pick, in latest.log, debug.log and the console, live.
Open Mod Menu -> Log Filter -> configure. Choices persist in `config/logfilter.json`.

Build: install JDK 25 + Gradle 9.5.1, then run `gradle build`.
Jar: `build/libs/logfilter-1.0.0.jar`.
Or push to GitHub: the included workflow builds the jar for you (Actions tab -> Artifacts).
